# Sin conexión (Wireless OK)

## ¿Cuándo corresponde este diagnóstico?

Utilizar este diagnóstico cuando:

- El CPE (antena) responde correctamente.
- El enlace wireless está operativo.
- El problema se encuentra entre el CPE y el router del cliente o en el propio router.

> Si el CPE no responde o presenta problemas de señal, utilizar el diagnóstico correspondiente.

---

# Paso 1. Verificar el CPE

Confirmar que el CPE:

- Responde por gestión.
- Tiene el enlace wireless operativo.
- No presenta reinicios, desenlaces o señal degradada.

---

# Paso 2. Verificar el enlace entre el CPE y el router

Comprobar:

- Estado del puerto Ethernet.
- Link activo.
- Velocidad de negociación.
- MAC del router (si está disponible).

Si no hay link, continuar con las verificaciones del cliente.

---

# Paso 3. Verificar el router

Solicitar al cliente que revise:

- Que el router esté encendido.
- Que la fuente esté conectada.
- Que el tomacorriente tenga energía.
- Que el cable entre el CPE y el puerto **WAN** esté correctamente conectado.
- Que no existan daños visibles en cables o conectores.

Si es posible, probar otra toma de corriente.

---

# Paso 4. Solicitar evidencia

Si es necesario, solicitar:

- Foto del router con las luces encendidas.
- Foto del CPE.
- Foto de los cables y conexiones.
- Foto de la fuente de alimentación.

---

# Paso 5. Reiniciar los equipos

Solicitar al cliente:

1. Desconectar el CPE y el router de la corriente.
2. Esperar **2 minutos**.
3. Conectar nuevamente ambos equipos.
4. Esperar que finalicen el encendido.

Verificar si el servicio se restablece.

---

# Paso 6. Si el router tiene link pero no navega

Verificar:

- Cliente autorizado en Hotspot.
- DHCP.
- ARP.
- Rutas.
- Firewall.

Registrar el resultado de cada verificación.

---

# Paso 7. Resolver el caso

### Si el servicio se restablece

Registrar:

- Pruebas realizadas.
- Resultado obtenido.
- Confirmación del cliente.

Cerrar el reclamo.

### Si el problema continúa

Derivar a Redes cuando exista:

- Falta de link entre el CPE y el router.
- Router sin respuesta.
- Problemas de alimentación.
- Cableado o conectores dañados.
- Router sin IP o sin navegación luego de las verificaciones.
- Necesidad de revisión en domicilio.

---

# Información obligatoria

Antes de derivar, registrar:

- Síntoma informado por el cliente.
- Estado del CPE.
- Estado del enlace.
- Resultado de las verificaciones.
- Evidencia recibida (si corresponde).
- Pruebas realizadas.
- Motivo de la derivación.
- Contacto y disponibilidad del cliente.

# Proceso para solicitar una e-sim:
- El pedido de e-sim (SIM electrónico) será solicitado por el Back office al gestor de la compañia que informe el cliente. (Claro/Movistar)
- Mediante el [Formulario](https://github.com/Eternet/Comercial.Movil/issues/new?assignees=&labels=E-SIM&projects=Eternet%2F103&template=Pedido_esim.yml&title=Cliente+%23+XXX+-+Razon+Social+-+Pedido+de+E-SIM) se solicitará y el back levantará el pedido que será gestionado de dos formas:
     - Claro: Mediante el portal web de la compañia. Es una gestión que requiere un feedback con el cliente ya que es en el momento y debemos asegurarnos de que le llegue correctamente.
     - Movistar: Mediante el TK en el portal. Se indicara a que linea se esta solicitando y luego cuando este listo, se adjuntará en el mismo TK. Nosotros debemos pasarlo al cliente 
- Una vez adquirido el código qr debemos enviarselo al cliente e informarle como configurarlo.

  # Proceso para configurar una e-sim: - Siempre con WIFI ACTIVO
  -  🚨 Dato importante 🚨 El e-sim tiene un tiempo limite de 48 horas para ser activado. Pasado ese período deberá solicitarse uno nuevo.
  -  Como activarlo: Desde un celular o tablet Apple: “Configuración” > “Red celular” > “Agregar plan de Datos” > “Escanear Código QR” > “Confirmar”.
  -  Si el cliente escanea el código desde la cámara de su dispositivo, la configuración quedará incompleta y no podrá realizar llamadas a ciertos números o recibir llamadas.

   # Posibles problemas que pueda presentar el e-sim:
   - Se encuentre vencido ya que se activó luego de las 48 horas de solicitado.
   - El escaneo se haya realizado desde la cámara del dispositivo y no desde la configuración.

### Tiempo de gestión

- Claro: Máximo de 24 horas hábiles (Lo enviamos desde Eternet con instructivo) 
- Movistar : Lo envía Movistar, con un máximo de 48 horas. Llega al mail del cliente con instructivo
- Para unificar criterio al cliente le informamos que puede demorar hasta 48 horas hábiles.
